# Automato — Protótipo V3 de hierarquia visual

## Alterações desta versão
- Remove os grandes fundos azuis dos contêineres e painéis internos dos componentes.
- Mantém as cores de identidade nos cabeçalhos, botões e estados ativos.
- Usa bordas neutras e leves para distinguir os níveis sem pintar toda a área.
- Define `stage > conteudo` como a área de rolagem principal.
- Remove a rolagem interna dos painéis comuns de MININAVEGAÇÃO, ABAS e SANFONA.
- Mantém a estrutura e os scripts de interação dos componentes.

## Observação de validação
Esta é uma versão de protótipo CSS. A regra de rolagem única precisa ser validada no navegador com o curso gerado, especialmente em painéis com muito conteúdo e em janelas flutuantes. Não considerar a validação visual/browser concluída apenas pela alteração dos estilos.
