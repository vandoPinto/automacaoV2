# Editor de Cursos EAD atualizado

## Executar
Abra `editor/index.html` diretamente no navegador ou use Live Server no VS Code.

## Estrutura
- `editor/index.html`: estrutura da interface
- `editor/css/styles.css`: estilos
- `editor/js/app.js`: lógica do editor e pré-visualização
- `editor/images/`: pasta para imagens estáticas

## Atualizações
- Campos de texto atualizam a pré-visualização enquanto você digita.
- A área de pré-visualização não é forçada a preencher a altura restante.
- Removidos os ornamentos decorativos `::before` e `::after` da área `.hero`.
- Incluído template específico “Imagem e texto”.
- Mantidos salvar localmente e exportação HTML/JSON.

Nota: protótipo local; dados são armazenados no navegador.
